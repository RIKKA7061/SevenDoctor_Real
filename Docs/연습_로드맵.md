# 연습 로드맵 — 빈 씬에서 손으로 다시 만들기

본편(`Assets/_Project`)은 건드리지 않고, `Assets/Practice` 에 빈 씬을 만들어 처음부터 끝까지 직접 짭니다.
그림·소리·CSV 는 본편 것을 그대로 가져다 씁니다. 코드 구조는 달라도 됩니다 — **플레이했을 때 겉으로 똑같이
움직이면 통과**입니다.

## 진행 방식

1. 단계 하나를 직접 구현합니다.
2. 채팅에 **"N단계 제출"** 이라고 씁니다.
3. 제가 `Assets/Practice` 의 변경을 읽고, 아래 '확인' 항목대로 되는지 · 버그가 있는지 · 다음 단계에서
   발목 잡힐 부분이 있는지 알려 드립니다. 코드는 대신 써 드리지 않습니다 (물어보면 힌트·설명은 드립니다).
4. 통과하면 다음 단계로. 커밋은 원하실 때 직접 하시면 됩니다 (main 에 바로).

막히면 각 단계의 '키워드' 로 먼저 찾아보고, 그래도 안 되면 '본편 참고' 파일을 열어 보세요.
처음부터 본편을 보면 연습이 베끼기가 됩니다.

## 시작 전에 알아 둘 것

- **입력은 Input System 만** 켜져 있습니다 (Project Settings → Player → Active Input Handling).
  `Input.GetKeyDown` 은 에러가 납니다. `UnityEngine.InputSystem.Keyboard.current.spaceKey.wasPressedThisFrame`,
  `Mouse.current` 를 쓰세요. UI 클릭을 받으려면 씬의 EventSystem 에 **InputSystemUIInputModule** 이 있어야 합니다.
- **이름이 겹치면 안 됩니다.** 본편 클래스(`GameBootstrap`, `UIRoot`, `DialogueRunner` …)는 `SevenDoctors` 네임스페이스에
  있습니다. 연습 코드는 전부 `namespace Practice { … }` 안에 넣으세요.
- **그림 불러오기**: 본편 그림은 `Assets/_Project/Resources/Art/...` 에 있어서 어디서든
  `Resources.Load<Sprite>("Art/Backgrounds/bg_lab")` 로 꺼낼 수 있습니다 (확장자 없이, `Resources/` 뒤 경로).
  인스펙터에 끌어다 놓아도 됩니다.
- **CSV**: `Resources/Data/*.csv` 도 `Resources.Load<TextAsset>("Data/Dialogues")` 로 읽힙니다.
  첫 줄은 머리글, 글자 안에 쉼표가 있으면 `"…"` 로 감싸져 있습니다.
- 화면 기준은 1920×1080 (Canvas Scaler → Scale With Screen Size).

## 1부 — 화면과 대화

### 0단계. 빈 씬
- `Assets/Practice/Scenes/Practice.unity` 빈 씬, `Assets/Practice/Scripts` 폴더.
- Canvas(1920×1080 Scale With Screen Size) + EventSystem(InputSystemUIInputModule).
- **확인**: Play 하면 에러 없이 빈 화면. 콘솔에 아무것도 없음.

### 1단계. 배경 한 장
- 화면 가득 연구실 배경(`bg_lab`)을 깝니다. 창 크기를 바꿔도 화면을 꽉 채움.
- **확인**: Game 창 비율을 16:9 / 16:10 / 프리 아스펙트로 바꿔도 빈틈 없음.
- 키워드: `Image`, `RectTransform` anchor stretch, `CanvasScaler`
- 본편 참고: `RoomController.ApplyBackground`

### 2단계. 대화창 한 줄씩
- 화면 아래 대화창: 이름표 + 본문. 코드 안에 적어 둔 대사 3~4줄을 클릭할 때마다 한 줄씩. 끝나면 창이 사라짐.
- 지문(화자 없음)이면 이름표를 숨깁니다.
- **확인**: 대화창 아무 데나 클릭하면 다음 줄. 마지막 줄 다음에 창이 닫힘.
- 키워드: `Button.onClick`, `Text`(또는 TextMeshPro), `SetActive`
- 본편 참고: `UI/DialogueView.cs`

### 3단계. 타이핑 효과
- 글자가 한 자씩 찍힘. 찍히는 중에 클릭하면 한 번에 다 나오고, 다시 누르면 다음 줄. 다 찍히면 ▼ 표시.
- 스페이스·엔터도 클릭과 똑같이.
- **확인**: 빠르게 연타해도 줄이 건너뛰어지지 않음 (클릭 한 번 = 한 단계).
- 키워드: 코루틴(`IEnumerator`, `yield return null`), `Time.deltaTime`
- 본편 참고: `DialogueRunner.ShowLine`

### 4단계. CSV 에서 대화 읽기
- `Dialogues.csv` 를 읽어 `dialogue_id` 로 묶고, `dlg_prologue_01` 을 재생합니다.
- `speaker_id` → `Characters.csv` 의 표시명으로 이름표.
- `다음대화` 칸이 있으면 이어서 그 대화로.
- **확인**: 게임을 켜면 본편 프롤로그와 같은 대사가 같은 순서로 나옴. 따옴표 안 쉼표가 있는 줄도 안 깨짐.
- 키워드: `TextAsset`, CSV 따옴표 처리, `Dictionary<string, List<…>>`
- 본편 참고: `Data/CsvParser.cs`, `Data/GameDatabase.cs`

### 5단계. 연출 태그 1
- 본문 속 `[…]` 는 화면에 안 보이게 지우고, `연출태그` 칸의 태그를 실행합니다:
  `[wait:초]`, `[fade_out]` / `[fade_in]`, `[shake]`, `[bgm:키]`, `[sfx:키]`
- **확인**: 프롤로그의 암전·흔들림·소리가 본편과 같은 자리에서 남.
- 키워드: 정규식 `\[([^\]]+)\]`, `CanvasGroup.alpha`, `AudioSource`
- 본편 참고: `Data/TagUtil.cs`, `DialogueRunner.ProcessPresentationTags`, `Audio/AudioManager.cs`

### 6단계. 포트레이트
- 말하는 인물의 그림(`Art/Portraits/{포트레이트키}`)을 화면에 세움. 지문이면 숨김.
- 글자가 찍히는 동안만 입 그림(`{키}_mouth`)을 켰다 껐다.
- `[portrait:인물:표정:방향]` — 방향(`side_left` 등) 그림이 있으면 바꿔 끼움, 없으면 정면.
- **확인**: 슬픔과 박사가 번갈아 말할 때 그림이 바뀌고 입이 움직임.
- 본편 참고: `UI/PortraitView.cs`, `UI/PortraitAnimator.cs`

## 2부 — 탐색

### 7단계. 방과 핫스팟
- `Rooms.csv` 로 방 배경, `Hotspots.csv` 로 클릭 영역. x·y·w·h 는 0~1 비율, **왼쪽 위 기준**.
- `이미지` 칸이 있으면 그 자리에 그림(`prop_*` / `chr:인물` / `shadow:인물`=검게), 없으면 투명 영역 + 깜빡이는 점.
- 누르면 `연결대화` 재생. 대사 중엔 핫스팟이 안 눌림. `move` 타입은 그 방으로 이동.
- **확인**: 연구실 → 레버 → 앞마당까지 본편과 똑같이 진행. 마우스를 올려도 글자·강조가 안 뜸.
- 본편 참고: `Room/RoomController.cs`, `Room/HotspotView.cs`

### 8단계. 플래그와 조건
- `[flag:x]` / `[unflag:x]` 로 켜고 끄기. `조건플래그`·`필요플래그`·`해금조건플래그` 칸 평가:
  `flg_a` / `!flg_a` / `flg_a,flg_b`(그리고) / `flg_a|flg_b`(또는).
- 1회성(`1회성` TRUE) 핫스팟은 한 번 누르면 사라짐.
- **확인**: 앞마당에서 나태를 만나기 전·후로 문을 눌렀을 때 하는 일이 바뀜.
- 본편 참고: `Core/Game.cs` 의 `FlagManager`

### 9단계. 선택지와 흐름
- `Choices.csv`: 그 줄에 선택지가 달려 있으면 버튼 목록, 고르면 `설정플래그` 켜고 `이동대화` 로.
- `[goto:dlg_x]`, `[room:room_x]`(대사 도중 방 전환).
- **확인**: 나태와의 대화에서 선택지에 따라 다른 대사.
- 본편 참고: `DialogueRunner.PlayCore`, `UI/DialogueView.cs` 의 `ChoiceView`

### 10단계. 증거와 노트
- `[get:ev_x]` → 증거 획득 알림(토스트), 상단바에 개수.
- Tab / 버튼으로 노트: 증거 칸 목록 + 고르면 그림·설명. 그림을 누르면 크게(휠 확대·드래그).
- 방에 인물이 있으면 '들이대기' → `AskTopics.csv` 반응 대사.
- **확인**: 프롤로그 뒤 증거가 노트에 보이고 크게 볼 수 있음.
- 본편 참고: `UI/NotebookView.cs`, `UI/EvidenceZoomView.cs`

### 11단계. 저택 지도
- M / 버튼: `Rooms.csv` 의 지도층·지도칸·지도폭으로 단면도. 지금 방 금색, 잠긴 방 어둡게.
- 방을 누르면 박사 얼굴 말(`prop_token_doctor`)이 길을 따라 걸어간 뒤 이동
  (같은 층은 옆으로, 다른 층은 계단 줄로). `지도연결` 은 열린 뒤에만 빨간 비밀 통로.
- **확인**: 본편 지도와 칸 배치가 같고, 말이 건물 안을 걷듯 움직임.
- 본편 참고: `UI/MapView.cs`

## 3부 — 퍼즐과 결말

### 12단계. 퍼즐
`Puzzles.csv` 의 타입별로 하나씩. 성공하면 `성공플래그` + `성공대화`, 실패하면 `실패대화`.
1. 숫자 자물쇠(CodeLock) — 가장 쉬움. 여기서 '퍼즐 창 열기 → 결과 → 닫기' 틀을 먼저 만드세요.
2. 슬라이딩(Slide) — 섞을 때 '풀 수 있는' 배치만 나오게.
3. 나머지(Deduction 추리 문장 채우기, 타일 금고, 퀸 배치).
- 본편 참고: `Puzzle/PuzzleDirector*.cs`

### 13단계. 지목과 엔딩
- 파트3 → 지목 → 파트4 → 비밀 통로로 지하실 → 파트5 → 엔딩 선택지.
- `[ending:end_x]` → 검은 화면에 엔딩명 + '처음으로'.
- **확인**: 세 엔딩을 다 볼 수 있음.
- 본편 참고: `UI/EndingView.cs`
