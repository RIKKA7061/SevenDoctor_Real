# 도우미 로봇 (힌트 시스템)

박사 옆에 떠 있으면서, 막혔을 때 힌트를 주는 로봇입니다.

## 규칙 하나

**먼저 말하지 않습니다.** 막혔다고 판단되면 안테나가 반짝이고 얼굴이 바뀔 뿐,
힌트는 플레이어가 로봇을 눌렀을 때만 나옵니다. 묻지도 않았는데 알려 주면
퍼즐을 푼 게 아니라 설명을 들은 게 됩니다.

## 로봇을 누르면

화면이 살짝 어두워지고 가운데에 창이 뜹니다. 위에 로봇 얼굴, 아래에 버튼 두 개.

| 버튼 | 하는 일 |
|---|---|
| 대화하기 | 힌트 — 로봇 옆 말풍선에 나옵니다 |
| 인벤토리 | 지금까지 얻은 단서 — 증거 노트가 열립니다 (`Tab` · 상단 버튼과 같은 창) |

창 바깥을 누르거나 `Esc` 를 누르면 그냥 닫힙니다. 창이 떠 있는 동안 `Tab` · `M` 은 먹지 않습니다.

노트는 탐색 중에만 열리므로, 대사나 퍼즐 도중에는 **인벤토리 버튼이 흐려져** 눌리지 않습니다 —
눌렀는데 아무 일도 없는 것보다 처음부터 못 누르는 게 낫습니다. 대화하기는 언제든 됩니다.

버튼 글자는 `UIStrings` 탭의 `ui.bot.talk` · `ui.bot.inventory` 입니다.

## 막혔다고 보는 기준

시간만으로 재면 대사를 읽거나 방을 구경하는 사람까지 막힌 걸로 잡습니다.
그래서 두 가지를 따로 봅니다. (숫자는 `HintDirector` 인스펙터에서 조정)

| 상황 | 기준 | 기본값 |
|---|---|---|
| 탐색 중 | 플래그도 증거도 안 늘어난 채로 핫스팟을 N번 누름 | 4번 |
| 탐색 중 | 아무것도 안 하고 가만히 있음 | 90초 |
| 퍼즐 중 | 퍼즐을 붙들고 있는 시간 | 60초 |
| 퍼즐 중 | 틀린 횟수 | 2번 |

방을 옮기는 핫스팟(`move`)은 세지 않습니다 — 그건 뒤지는 게 아니라 이동입니다.
플래그가 켜지거나 증거를 얻으면 **센 것이 전부 초기화**됩니다. 힌트 단계까지
되돌아가므로, 1장에서 세 번 물어본 사람이 2장 첫 힌트부터 정답을 듣는 일은 없습니다.

## 힌트 쓰기 — `Hints` 탭

```
hint_id, 대상퍼즐, 조건플래그, 단계, 힌트, 힌트_en, 비고
```

- **대상퍼즐이 비어 있으면** 진행 힌트입니다. 탐색 중에 막혔을 때 씁니다.
  조건플래그가 맞는 것 중 **시트에서 제일 위**에 있는 상황이 뽑히므로,
  **시트를 이야기 순서대로 적어 두세요.** 그러면 저절로 지금 챕터가 나옵니다.
- **대상퍼즐이 채워져 있으면** 그 퍼즐이 떠 있을 때만 뽑힙니다.
- **단계**는 같은 상황에서 다시 물었을 때 얼마나 더 알려 줄지입니다.
  1은 방향만, 숫자가 커질수록 답에 가깝게 적으세요. 마지막 단계에 도달하면
  계속 눌러도 그 줄이 반복됩니다 — 빈 말풍선은 나오지 않습니다.

퍼즐에 전용 힌트를 안 적어 두면 `Puzzles` 탭의 `힌트텍스트` 칸으로 버팁니다.
그것도 없으면 `ui.hint.none` 이 나옵니다.

## 그림

`Art/Bot/bot_body` 위에 `Art/Bot/bot_face_{표정}` 을 겹칩니다. 표정은
`normal` `happy` `curious` `hint` `sleepy` `panic` 여섯 개이고, 얼굴이
'검은 화면 위의 빛나는 눈' 이라 **눈만 갈아끼우면 표정이 전부 나옵니다.**
지금 그림은 `gen_art.py` 의 도형 로봇입니다 (`python ArtSource/gen_art.py`).

턴어라운드 시트(`ArtSource/sheets/bot_turnaround.webp`)로 만든 새 로봇도 있습니다.
`python ArtSource/cut_bot.py` 로 뽑을 수 있지만, 그러면 `HelperBotView` 의 숫자도 같이 바꿔야 합니다 —
칸 크기(`BotSize`)는 168×214, 안테나 칸(`AntennaRoom`)은 0 으로, 막힘 불빛은 안테나 대신
머리 위 전구 자리(스크립트가 출력하는 BulbPoint)로. (그 뒤에 `gen_art.py` 를 돌리면 도형 로봇으로 다시 덮어씁니다.)

PNG 가 없으면 얼굴판 색만 바꿔 기분을 표시합니다. 아트가 들어오면 저절로
그림 쪽으로 넘어가고 코드는 안 바뀝니다.
