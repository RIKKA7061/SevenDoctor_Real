# SevenDoctors — 개발 메모

유니티 6000.3.22f1 (URP 2D) / 2D 포인트 앤 클릭 추리 어드벤처

---

## 1분 만에 실행하기

1. 유니티에서 프로젝트를 엽니다 (컴파일이 끝날 때까지 기다립니다)
2. 메뉴 **Tools → 일곱 박사 → 게임 씬 만들기**
   (Game 씬 + UI 프리팹이 한 번에 만들어집니다)
3. **Play**

프롤로그(연구실 사고 → 저택 앞 → 나태 조우 → 거실 → 창고 자물쇠 → 복도 추리)까지
샘플 데이터로 실제로 끝까지 돌아갑니다. 아트가 하나도 없어도 동작합니다.

조작: 핫스팟 버튼 클릭 / 대화창 아무 데나 클릭해서 진행 / `Tab` 또는 우상단 버튼으로 증거 노트

## 이 구조를 택한 이유

### 씬이 4개가 아니라 1개인 이유
방 8개를 각각 씬으로 만들면 방을 옮길 때마다 매니저를 다시 찾아야 하고,
플래그·증거 같은 상태를 씬 사이로 넘기는 코드가 계속 늘어납니다.
`Game.unity` 하나에서 배경과 핫스팟만 교체합니다.

### UI 는 '코드로 만들어서 프리팹으로 굳히는' 방식
UI 계층을 만드는 코드는 `UIRoot.CreateFromCode()` **하나뿐**이고,
**Tools → 일곱 박사 → UI 프리팹 만들기** 가 그걸 에디터에서 한 번 실행해 결과를
`Assets/_Project/Resources/UI/UIRootCanvas.prefab` 으로 저장합니다.

- 프리팹이 있으면 → 런타임이 그걸 꺼내 씁니다. **Hierarchy·Inspector 에서 손으로 고친 값이 그대로 반영됩니다.**
- 프리팹이 없거나 구조가 코드와 안 맞으면 → 코드 생성으로 자동 폴백하고 경고를 남깁니다. 게임은 안 멈춥니다.

씬 파일에는 여전히 카메라와 `GameBootstrap` 둘만 들어 있습니다.
3인이 한 저장소를 쓸 때 가장 심하게 충돌하는 게 씬 파일인데, UI 가 프리팹 하나에 모여 있으면
그 파일을 동시에 건드릴 때만 충돌합니다.

**코드로 UI 구조를 바꿨으면 프리팹을 다시 만드세요.** 안 그러면 폴백이 돌면서 손으로 고친 값이 무시됩니다.

### 구글 시트를 런타임이 아니라 에디터에서 받는 이유
런타임에 시트를 직접 때리면 빌드본이 네트워크에 의존하게 됩니다.
오프라인이면 게임이 안 켜지고, 발표·시연 중 네트워크 사고는 반드시 일어납니다.
대신 기획자가 시트를 고치고 **Tools → 일곱 박사 → 시트 가져오기** 에서 버튼 한 번 누르면 즉시 반영됩니다.
체감은 실시간 연동과 같고, 리스크만 없습니다.

### TextMeshPro 대신 레거시 Text 를 쓰는 이유
TMP 는 한글 폰트 에셋을 따로 굽지 않으면 글자가 아예 안 나옵니다.
지금 단계에서 그 작업을 강제하고 싶지 않아서 OS 폰트(맑은 고딕)를 쓰는 레거시 Text 로 갔습니다.
아트 확정 후 TMP 로 갈아타려면 `UI/UIFactory.cs` 한 파일만 고치면 됩니다.

## 기획자와의 작업 흐름

1. 기획자가 구글 시트를 고칩니다 (탭 11개, 컬럼 정의는 `기획시트_템플릿.xlsx` 참고)
2. 시트 공유를 **'링크가 있는 모든 사용자 - 뷰어'** 로 설정
3. 유니티에서 **Tools → 일곱 박사 → 시트 가져오기** → 스프레드시트 ID 입력 → 가져오기
4. 가져온 직후 **무결성 검사가 자동으로 돌아서**, 깨진 ID 참조를 전부 잡아줍니다

무결성 검사는 이 프로젝트에서 가장 값싼 보험입니다.
`dlg_livin_sloth` 처럼 오타 하나만 나도 게임이 조용히 멈추는데,
그걸 플레이해보고 찾는 것과 콘솔에서 한 줄로 보는 건 디버깅 시간이 열 배 차이 납니다.

**Tools → 일곱 박사 → 데이터 검사** 로 언제든 따로 돌릴 수 있습니다.

## 기획자가 외울 문법 (연출태그)

`Dialogues` 탭 '연출태그' 칸에 씁니다. 여러 개는 그냥 이어 붙입니다. 예) `[sfx:door][fade_out]`

| 태그 | 의미 | 상태 |
|---|---|---|
| `[flag:flg_x]` | 플래그 켜기 | 동작 |
| `[unflag:flg_x]` | 플래그 끄기 | 동작 |
| `[get:ev_x]` | 증거 획득 | 동작 |
| `[goto:dlg_x]` | 다른 대화로 점프 | 동작 |
| `[puzzle:pzl_x]` | 퍼즐 시작 | 동작 |
| `[shake]` | 화면 흔들기 | 동작 |
| `[fade_out]` / `[fade_in]` | 암전 / 복귀 | 동작 |
| `[wait:0.5]` | 대기 | 동작 |
| `[bgm:x]` / `[sfx:x]` | 사운드 | 동작 |
| `[portrait:chr_x:angry]` | 표정 변경 | 동작 |

대화 시스템 자체를 고치는 방법(새 태그 만들기, 칸 추가 등)은 `Docs/대화시스템.md` 에 있습니다.

조건 칸(`조건플래그` / `필요플래그`)은 이렇게 씁니다:

```
flg_a              flg_a 가 켜져 있을 때
!flg_a             flg_a 가 꺼져 있을 때
flg_a,flg_b        둘 다 켜져 있을 때 (AND)
flg_a|flg_b        둘 중 하나라도 (OR)
```

## 핫스팟 좌표

`Hotspots` 탭에 `x / y / w / h` 컬럼이 있습니다. **정규화 좌표(0~1), 화면 좌상단 기준**입니다.

- **비워두면**: 화면 하단에 이름표가 보이는 버튼으로 자동 배치됩니다.
  배경 아트가 없어도 기획자가 동선을 바로 확인할 수 있습니다.
- **채우면**: 그 자리에 투명한 클릭 영역이 생깁니다. 배경 아트가 들어온 뒤에 채우세요.

예) 화면 왼쪽 위 1/4 영역 → `x=0, y=0, w=0.5, h=0.5`

## 아트

**지금 플레이스홀더 아트가 들어가 있습니다.** 실제 아트가 나오면 같은 경로·같은 파일명으로
덮어쓰기만 하면 코드는 한 줄도 안 고쳐도 됩니다.

```
Resources/Art/
├── Backgrounds/{배경키}.png    1920×1080   ← Rooms 탭 '배경키'와 파일명 일치
├── Characters/{포트레이트키}.png  700×1200   ← Characters 탭 '포트레이트키'와 일치 (몸)
├── Faces/{표정}.png            700×1200   ← Dialogues 탭 '표정'과 일치 (표정만, 투명 배경)
└── Evidence/{아이콘키}.png       512×512    ← Evidence 탭 '아이콘키'와 일치
```

**PNG 를 폴더에 넣기만 하면 됩니다.** Texture Type 을 Sprite 로 바꾸는 작업은
`ArtImportSettings.cs` 가 자동으로 해줍니다. (한 번만 깜빡해도 "왜 배경이 안 나오지"로
한참 헤매게 되는 사고라, 아예 막아놨습니다)

### 몸과 표정을 나눈 이유

일곱 박사가 전부 같은 얼굴이라는 게 설정이므로, **표정 한 세트를 전원이 공유**합니다.
7인 × 5표정 = 35장이 아니라, 몸 8장 + 표정 5장 = 13장이면 끝납니다.
아트 담당 작업량이 1/3 이하로 줄어듭니다.

- 몸: 인물마다 옷깃 강조색 + 소품 하나로 구별 (교만만 얼굴이 어둠에 묻힌 버전)
- 표정: `normal / surprised / angry / sad / sleepy` — 몸과 같은 캔버스 크기, 얼굴 부분만 그리고 나머지는 투명

새 표정을 추가하려면 같은 규격으로 PNG 를 넣고 시트 '표정' 칸에 그 이름을 쓰면 됩니다. 코드 수정 불필요.

### 플레이스홀더를 다시 뽑고 싶으면

`ArtSource/gen_art.py` (파이썬 + Pillow). 색·비율·구도가 전부 숫자로 되어 있어서
값만 바꿔 다시 돌리면 됩니다.

```
python ArtSource/gen_art.py
```

Live2D 는 이번엔 제외합니다. 표정 교체만으로도 충분히 살아 움직입니다.

## UI 를 눈으로 고치고 싶을 때

1. Project 창에서 `Assets/_Project/Resources/UI/UIRootCanvas` 더블클릭
   (또는 **Tools → 일곱 박사 → UI 프리팹 열기**)
2. Hierarchy 에서 원하는 오브젝트를 골라 Inspector/Scene 뷰에서 수정
3. 저장하면 다음 Play 부터 바로 반영됩니다

이름은 바꾸지 마세요. 코드가 이름으로 찾아 연결합니다
(`DialoguePanel/Body/Text` 같은 경로). 이름이 바뀌면 폴백이 돌면서 수정이 무시됩니다.
