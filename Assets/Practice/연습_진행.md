# 연습 씬 진행 노트

다른 노트북에서 Claude와 새 대화를 열 때 이 파일을 보여 주면 그대로 이어집니다.

## 이 연습의 규칙

- **목표:** 이미 만들어진 `Game` 씬과 구조는 달라도, 겉으로 보기에는 똑같이 작동하는 씬을 **내가 직접** 만든다.
- **Claude의 역할:** 단계마다 과제와 힌트만 준다. 코드는 내가 짠다. 막히면 묻고, 원할 때만 리뷰를 받는다.
  정답 코드는 먼저 보여 주지 않는다 (막혀서 요청하면 그때).
- **브랜치:** `practice` 에서만 작업. main(진짜 게임)에 섞지 않는다.
- **폴더:** 전부 `Assets/Practice/` 아래 (`Scene/Practice.unity`, `Scripts/`).
- **네임스페이스:** 스크립트는 `namespace Practice { ... }` 로 감싼다 — 진짜 게임 클래스와 이름이 겹치지 않게.
- **데이터·그림은 진짜 게임 것을 읽기만 한다:** `Assets/_Project/Resources/Data/*.csv`, `Assets/_Project/Resources/Art/`.
  진짜 게임 스크립트(`SevenDoctors.*`)는 쓰지 않고 참고만 한다.
- ⚠️ 연습 코드에 컴파일 오류가 있으면 Game 씬도 실행이 안 된다. 오류를 오래 남겨 두지 않기.

## 전체 순서

## 지금까지 한 것

### 1단계 — 연구실 배경 (거의 끝)

- 씬: `Assets/Practice/Scene/Practice.unity`
  - Canvas (Screen Space – Overlay, Canvas Scaler: Scale With Screen Size, 1920×1080, Match 0.5)
  - 그 아래 `Background` Image — 화면 전체로 늘림, Source Image 는 비워 둠
- 스크립트: `Assets/Practice/Scripts/PracticeRoom.cs` (Canvas 에 붙임)
  - `[SerializeField] private Image background;` 에 `Background` 를 연결
  - `Start()` 에서 `Resources.Load<Sprite>(경로)` 로 불러와 `background.sprite` 에 넣음
  - 못 찾으면(`null`) `Debug.LogWarning` 으로 알림

**남은 것**
- [ ] 경로 고치기: 폴더 이름은 `Backgrounds` (끝에 s) → `"Art/Backgrounds/bg_lab"`
- [ ] 경고 메시지에 어떤 경로를 못 찾았는지 같이 적기 (경로를 변수에 담아 `Load` 와 메시지 양쪽에 쓰기)
- [ ] 확인이 끝난 성공 로그는 지우기
- [ ] `namespace Practice { }` 로 감싸기

**끝났다는 기준:** Source Image 가 비어 있어도 Play 하면 연구실이 화면에 꽉 차게 나오고, 창 크기를 바꿔도 찌그러지지 않는다.

### 1단계에서 배운 것

- `Resources.Load` 경로는 **Resources 폴더 안에서부터, 확장자 없이**. 실제 파일이
  `Assets/_Project/Resources/Art/Backgrounds/bg_lab.png` 이면 경로는 `Art/Backgrounds/bg_lab`.
- 경로가 틀리면 오류 없이 **`null`** 을 돌려준다 → Image 가 흰 네모로 보인다. 그래서 null 검사가 필요하다.
- Project 창에서 폴더를 클릭하면 창 아래에 실제 경로가 나온다 — 거기서 옮겨 적으면 오타가 없다.
- 인스펙터에 끌어다 놓는 건 에디터에서만 된다. 게임 중에 "이 이름의 그림" 을 고르려면 코드로 불러와야 한다 (2단계의 준비).
- 변수 이름은 '무엇이 들어 있는지' 로 짓는다 (씬 오브젝트를 `...Prefab` 이라 부르지 않기).

## 겪은 문제와 해결

- **Visual Studio 에서 `Image` 에 색이 안 들어옴 (Unity 콘솔엔 오류 없음):**
  Unity → Edit → Preferences → External Tools 에서 External Script Editor 를 Visual Studio 로,
  'Generate .csproj files for' 의 패키지 항목들을 켜고 Regenerate project files → Visual Studio 다시 열기.
